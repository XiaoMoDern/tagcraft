Why Etsy tags must stay under 20 characters

Etsy allows up to 13 tags per listing, and each tag has a hard limit of 20 characters. If a tag is 21 characters or longer, Etsy won't let you save it — you lose that tag slot and the search traffic that comes with it.

How to use this tool

  • Paste the tags you've written (or copy them from a spreadsheet).
  • Each tag is counted individually — spaces and punctuation included.
  • Tags over 20 characters are highlighted in red; shorten them or replace them.

Frequently asked questions

How many tags can I use on Etsy?

Etsy gives you 13 tag slots per listing. Use all 13 — each tag is another chance to be found in search.

How long can each Etsy tag be?

20 characters maximum, including spaces. This counter flags anything over that limit.

What happens if my tag is over 20 characters?

Etsy rejects the tag, so the slot is wasted. Better to shorten it to a 2–4 word phrase that still captures the search intent.
