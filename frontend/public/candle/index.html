Why candle SEO matters on Etsy

Candles are one of Etsy's fastest-growing categories, which also makes them crowded. Buyers rarely search for a single word like "candle" — they search for specifics: "lavender soy candle", "wood wick candle", "8 oz scented candle gift". If your title and tags only repeat one generic keyword, your listing gets buried. Covering scent + wax type + size + occasion + audience is what makes a candle listing findable.

How to write an Etsy candle title

  • Lead with wax type + scent — "Lavender Soy Candle" outranks "Relaxing Candle for Home" because the first 30-40 characters carry the most search weight.
  • Add the size or vessel — 8 oz, 12 oz, tin, amber jar, travel tin.
  • Then occasion or benefit — relaxing, home decor, housewarming, wedding favor.
  • End with audience — gift for her, gift for mom, candle lover.

How to choose candle tags (13 slots)

Etsy gives you 13 tags, each up to 20 characters. Don't repeat the same keyword — split them across search intents:

  • Scent: lavender candle, vanilla candle, citrus candle, eucalyptus candle
  • Wax type: soy candle, beeswax candle, coconut wax candle
  • Size / vessel: 8 oz candle, 12 oz candle, amber jar candle, tin candle
  • Occasion: home decor candle, wedding favor, housewarming gift
  • Audience: gift for her, gift for mom, candle gift set
